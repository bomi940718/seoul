## 4. UI 설계 방향 (사용자 지시 반영)

> "각 법 우측에 해당 법규를 작성 — 표로 되어 있으니 따로 행으로 구분할 필요 없이 UI도 잡힌다"

**설계개요 입력을 그리드 1개로 만든다.** 세로 나열식 폼을 버리고, 검토서 p3와 **같은 모양의 표**를 그대로 화면에 띄운다:

```
구분          │ 계획          │ 법정          │ 법규(근거)
──────────────┼───────────────┼───────────────┼──────────────────
건축면적      │ [입력]        │ (자동계산)    │ [입력]
건폐율        │ (자동)        │ [입력 %]      │ [입력]
연면적        │ (자동)        │ (자동계산)    │ [입력]
용적률        │ (자동)        │ [입력 %]      │ [입력]
건축규모      │ [지상][지하]  │ [입력]        │ [입력]
최고높이      │ [입력]        │ [입력]        │ [입력]
조경면적      │ [입력]        │ (자동)        │ [입력]
주차-주차형식 │ [입력]        │ -             │ [입력]
주차-옥내     │ [입력]        │ -             │
주차-옥외     │ (자동)        │ (자동)        │
주차-장애인   │ (자동)        │ (자동)        │
주차-확장형   │ (자동)        │ (자동)        │
주차-친환경   │ (자동)        │ (자동)        │
주차-전체     │ (자동)        │ (자동)        │
```

모드에 따라 열만 바뀐다:
- **신축**: 구분 │ 계획 │ 법정 │ 법규
- **리모델링·증축·용도변경**: 구분 │ 변경전 │ 변경후 │ 법정 │ 법규
