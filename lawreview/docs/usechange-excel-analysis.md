### 1~9 절차

1. **용도변경 가능 여부** — 건축물대장 발급/열람, 불법건축물 유무, 용도지역별 규제, 지구단위계획 용도제한
2. **용도변경 기준 선정** — ①허가(상위군) ②신고(하위군) ③건축물대장 기재사항 변경(동일 시설군) ④변경 없이 사용(같은 호)
   - 허가 대상 + 바닥면적 합계 500㎡ 이상 → **건축사 설계 필수**(개인 진행 불가)
   - 1종↔2종 근생 상호변경은 변경 없이 사용 가능. **단 단란주점·안마시술소·안마원·노래연습장·고시원 제외**(기재사항 변경 필요)
3. **9개 시설군 표** (자·산·전·문·영·교·근·주 + 그 밖) — 상위/하위군 판정의 기준표
4. **법규 검토 11항목** — 입지 적합, 지구단위계획 허용용도, 영업 허가 적합, 주차대수, 정화조, 소방시설, 장애인 편의, 피난시설, 위법사항, 창호, 내화·방화·피난
5. **신청 도서 6종**
6~9. 공사 시행 → 사용승인 신청 → 검토·현장확인 → 사용승인서 발급(건축물대장 변경 완료)

## 5. C.용도변경 수수료

- **건축허가 수수료**(건축법 시행규칙 제10조): 연면적 구간별 8단계 (200㎡ 미만 ~ 30만㎡ 이상)
- **하수도 원인자부담금** (안양시 하수도 조례 제19조의2③)
  - 산정식: `업종별 1일 오수발생량(㎥/일) × 바닥면적(㎡) × 지자체 단위단가(원)`
  - D22 = `A.체크리스트!D7` ← **시트 간 참조** (용도변경 면적)
  - D26 = `(D24-D25) * D22 * D23` — (기존 오수량 − 변경 오수량) × 면적 × 단가
  - 2025년 안양시 단위단가 **1,782,000원/㎥**
  - ⚠ 원인자부담금은 통상 **증가분**(변경−기존)에 부과되는데 수식은 (기존−변경) 순서다. 착수 시 사용자 확인 필요.

## 6. 2.개요 — 산출물 핵심 (정량 계산)

### 상단 기본정보 (A.체크리스트에서 자동 인용)

| 셀 | 수식 |
|---|---|
| F5 대지위치 | `=INDEX(A.체크리스트!D6,1,1)&" "&INDEX(A.체크리스트!E6,1,1)` |
| F6/F7 지역·지구 | `=A.체크리스트!D10` / `=A.체크리스트!D11` |
| D11 변경전 용도 | `=A.체크리스트!D8` |
| D12 변경 내용 | `=INDEX(A!D9,1,1)&" -> "&INDEX(A!E9,1,1)` → `(사무실) -> (학원)` |
| D13 변경후 용도 | `=A.체크리스트!E8` |
| G12 면적 | `=A.체크리스트!D7` |

- 대지: **지번 3개까지**(G/H/I열) + 총계 `G10=G9+H9+I9`
- 용도변경 대상: **층/호수 3개까지**(G11/H11/I11, 예 "3층 / 301호") + 면적 합계 `G13=G12+H12+I12`

### 비교표 구조 — 4열 대비 (용도변경 특유)

`구분 | 변경전(F) | 변경후(G) | 법정(H) | 법규 근거(I)`

기존 신축용 검토서는 "계획 vs 법정" 2열인데, **용도변경은 변경전·변경후를 나란히 비교**한다. 이게 가장 큰 구조 차이.

| 항목 | 법정값 셀 | 산정식 |
|---|---|---|
| 건폐율 | H21 (예 0.7) | H19 = `G9*H21` → 법정 건축면적, F23/G23 = `면적/G10*100` |
| 용적률 | H27 (예 3.5) | H25 = `G9*H27`, F29/G29 = `연면적/G10*100` |
| 건축규모(층) | H30 | 직접 입력 |
| 최고높이 | H31 | 직접 입력 |
| 조경면적 | H32 (예 0.05) | H33 = `G10*H32` → "301.51 m² 이상" |
| 주차 | H34 (예 200) | 아래 참조 |

표기 규약: 값이 아니라 **산정식 문자열을 그대로 생성**한다.
예: `H18 = TEXT($G$10,"#,##0.00 m²") & " x " & FORMULATEXT(H21)` → `6,030.10 m² x 0.70`

### 주차 계산 (LAMBDA/LET) — 4종

| 종류 | 기준 셀 | 조건 |
|---|---|---|
| 법정 주차 | H34 (시설면적/대) | `면적/기준` → `= 105.53 대 (106 대)` (ROUND) |
| **장애인전용** | H37 (3%) | 총 주차 **10대 미만이면 "해당 없음"**, 이상이면 `총대수 × 3%`, 결과 <1이면 **1대**, 아니면 ROUND |
| **확장형** | H40 (3%) | 총 주차 **50대 미만이면 "해당 없음"** |
| **친환경** | H43 (3%) | 총 주차 **50대 미만이면 "해당 없음"** |
| 전체 표기 | — | 10대 미만 `"9 대"`, 이상 `"88 대(장애인 포함)"`, 법정열은 `"106 대 이상(장애인 포함)"` |

> 기존 도구의 `QuantitativeCalculator`와 규칙이 거의 같지만, **확장형·친환경 주차(50대 기준)는 현재 미구현**이다. 이식 시 추가 필요.

## 7. 1.검토요약 / 4.법규(요약) / 5.관련법규 — 산출 구조

- **1.검토요약**: `▼법규 그룹` → `번호 항목` → `1) 2) 근거 설명` → `▷ → 결론 한 줄`.
  D열은 `[관련 법규 상세 사항] '<그룹명>' 참고`로 5.관련법규와 연결.
  하단에 **건축물대장 기재사항 변경 진행 순서 1~8** 별도 표.
- **4.법규(요약)**: `법규명 및 조항 | 대상 | 법적 기준 | 설계 기준(산정식) | 비고(적용/해당없음)`
  → 기존 도구의 요약 검토표와 **컬럼 구성이 사실상 동일**. 값은 전부 `='2.개요'!…` 참조.
- **5.관련법규**: `▼법규 그룹` → `구분 | 항목 | 내용(조문 원문) | 적용여부`.
  → 기존 도구의 장별 상세검토에 대응. **부칙 적용례**(방화유리창·소방관진입창)까지 인용하는 점이 특징.
- **3.법규**: 검토법규 목록 + **개정일자**. 기존 도구는 시행일자를 API에서 가져오므로 자동화 가능.

## 8. 자동화 이식 시 결정 사항

### 그대로 재사용 가능
- 주소 → 지역·지구·대지면적 자동조회 (VWorld) — A.체크리스트 0번 기본정보와 정확히 대응
- 지구단위계획 근거 (포털 자동조회 / 직접 등록)
- 법제처 조문 원문 인용 (3.법규 개정일자 = 시행일자 자동)
- 요약 검토표·상세검토 DOCX 생성 골격

### 새로 만들어야 하는 것
1. **변경전/변경후 2열 비교** — 현 모델은 단일 계획값만 담는다. `ProjectInput`에 before/after 개념 추가 필요
2. **건축물대장 정보** — 사용자 요청: 층별 면적 / 건축주 / **완공일(사용승인일)**.
   완공일은 주차 면제(5년 경과) 판단에 **직접 쓰인다** → 단순 표기가 아니라 판정 입력값
3. **시설군 판정 로직** — 9개 시설군 표 기반으로 허가/신고/기재사항변경/변경없음 자동 분류 (코드로 결정 가능)
4. **주차 차이분 계산** — 변경후 − 변경전, 면제 조건 2가지 반영
5. **확장형·친환경 주차** (50대 기준) 추가
6. **오수량·원인자부담금 계산** — 업종별 원단위 필요(별도 자료), 지자체 단위단가는 입력값
7. **용도변경 전용 체크리스트** — 기존 54항목이 아니라 B시트의 7개 축 + A시트 11항목 기준으로 축소 재구성

### 확인 필요 (사용자에게 물어볼 것)
